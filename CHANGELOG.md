# Changelog

## 2.0.0

- Standalone food familiarity and nutrition; Diet is optional.
- Four journal tabs with food-stage forecasts, nutrition thresholds, secret groups and effect sources.
- Datapack food profiles, groups, nutrition scales, compound rules, formulas and NBT variants.
- Configurable nutrition decay, death loss, stage penalties and food-effect filters.
- Server API, Forge events and optional integrations for custom feeding and recipe calculations.
- Deduplicated group membership after resource reload; authoritative client membership sync.
- Explicit datapack CCI takes precedence over an old automatic cache; manual configuration retains priority.
- Installable datapacks are maintained in the separate l-diediet-datapacks repository.
- MIT license.
